# Gestor de Viviendas para Propietarios

Aplicación de escritorio desarrollada en C# con Windows Forms orientada a propietarios que necesiten gestionar sus viviendas en alquiler.  
Permite administrar inquilinos, contratos, pagos y consultar el estado de cada propiedad.
